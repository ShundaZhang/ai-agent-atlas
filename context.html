01 / FIELD NOTES

Context, memory and weights are different storage

A long conversation is not the same as unlimited working memory.

StoreContentFailure to consider
Model weightsLearned parametersStale or unreliable recall; not a precise document store
Current contextInstructions, selected messages and tool resultsOverflow, irrelevant material or omitted evidence
Application memorySaved notes or structured recordsWrong scope, stale conclusions or cross-user leakage
Workspace artifactsFiles, patches, logs and checkpointsA summary disagrees with current files

Preserve decisions, unresolved questions, source locations and the current artifact revision when compacting. Mark what is observed versus inferred. A summary is lossy; re-open the source when precision matters. Treat instruction text, external evidence and tool observations as distinct inputs.

02 / FIELD NOTES

RAG is an evidence pipeline

Retrieval determines what the generator has the chance to use.

Ingest documents with versions and permissions, split meaningful chunks, index them, retrieve candidates, rerank or filter, and supply selected passages with provenance. Dense embeddings support semantic similarity; keyword and hybrid search help exact identifiers. Similarity is not truth or permission. Apply resource access checks before private passages enter the model context.

Separate retrieval recall from grounded answer accuracy. First ask whether the necessary passage was found, then whether the answer faithfully used it. Test no-answer cases and conflicting revisions. RAG does not guarantee that the model uses the right passage or that an embedded instruction in a document is harmless.

03 / FIELD NOTES

Budget for the next useful observation

Allocate space for instructions, evidence, tool results and the output.

Keep the exact acceptance condition and a small authoritative excerpt. Reference large files by stable locations; inspect selected regions rather than pasting every log. Reserve output and reasoning space according to the selected model’s actual accounting. Prompt caching may reduce repeated-prefix cost or latency; it is not application memory or a permission boundary.

The context-budget exercise uses invented units to demonstrate selection. It does not tokenize text, estimate an OpenAI bill or model attention quality.
