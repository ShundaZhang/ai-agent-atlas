01 / FIELD NOTES

从文本到概率分布

Token 是模型词表中的元素，不一定等于单词或字符。

分词器将输入映射为 token ID；嵌入查表将 ID 映射为向量，位置信息用于区分顺序。Decoder 风格的 Transformer 将表示转换成候选下一个 token 的 logits，softmax 得到概率分布；选出的 token 加入前缀，继续下一步。

Token 可以包含词的一部分、空白或标点。中文、源代码和混合语言的分词模式不同。需要精确控制限制时应使用实际分词器；字符数估计仅是粗略近似。

P(x₁…xₙ) = ∏ᵢ P(xᵢ | x₁…xᵢ₋₁) L(θ) = − Σᵢ log Pθ(xᵢ | x<ᵢ)

02 / FIELD NOTES

注意力机制做了什么

每个位置从当前表示计算 query、key 和 value。

Query / key 分数决定某个位置读取其他允许位置的 value 的权重。自回归 decoder 的因果掩码禁止读取未来 token。多头使用不同投影，前馈块、残差连接和归一化在多层中变换并稳定表示。单个注意力权重不能可靠解释整个模型的决策。

Attention(Q,K,V) = softmax(QKᵀ / √dₖ + mask)V Q = XWQ, K = XWK, V = XWV

这是 decoder Transformer 的教学示意。2017 年原论文描述 encoder–decoder 模型；当前系统可采用不同位置编码、注意力变体、混合专家及多模态组件。

03 / FIELD NOTES

为什么合理表达可能不真实

语言概率不等于事实核验过程。

模型可以泛化模式、解决问题并组合证据，但仍可能编造引文、混淆日期或生成细微错误的程序。缺失事实、任务歧义、误导上下文和验证不足都可能导致失败。语法正确和表达自信不能校准主张的真实性。

应按主张选择外部反馈：引文核对原文，计算执行核验，行为使用回归检查，动作检查权限。通过测试也仅支持给定条件下被测属性。
