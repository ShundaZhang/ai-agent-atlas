01 / FIELD NOTES

From text to a probability distribution

A token is an element of the model’s vocabulary, not necessarily a word or character.

A tokenizer maps input to token IDs. Embedding lookup maps each ID to a vector; position information distinguishes order. A decoder-style Transformer transforms these representations into logits for candidate next tokens. A softmax turns logits into a distribution. After a token is selected, it becomes part of the prefix for the next step.

Tokens can span part of a word, whitespace or punctuation. Chinese, source code and mixed-language text have different tokenization patterns. Count with the actual tokenizer when a limit matters; character-count heuristics are only rough estimates.

P(x₁…xₙ) = ∏ᵢ P(xᵢ | x₁…xᵢ₋₁) L(θ) = − Σᵢ log Pθ(xᵢ | x<ᵢ)

02 / FIELD NOTES

What attention contributes

Each position forms queries, keys and values from its current representation.

A query/key score determines how strongly one position reads values from other permitted positions. Causal masking prevents reading future tokens in an autoregressive decoder. Multiple heads learn different projections; feed-forward blocks, residual connections and normalization transform and stabilize representations through successive layers. An attention weight is not a reliable explanation of the entire model’s decision.

Attention(Q,K,V) = softmax(QKᵀ / √dₖ + mask)V Q = XWQ, K = XWK, V = XWV
Architecture scope

This is a teaching sketch of a decoder Transformer. The original 2017 paper describes an encoder–decoder model. Current systems can use different position encodings, attention variants, mixtures of experts and multimodal components.

03 / FIELD NOTES

Why plausibility and truth can diverge

A language probability is not a fact-verification procedure.

The model can generalize patterns, solve problems and combine evidence, yet still invent a citation, confuse a date or produce a subtly wrong program. A missing fact, ambiguous task, misleading context or weak verification can all cause failure. Correct grammar and confidence do not calibrate the probability that a claim is true.

Use external feedback appropriate to the claim: a source passage for a quotation, execution for a calculation, a regression for a behavior and a permission check for an action. Even a passed test only supports the tested property under the stated conditions.
