01 / FIELD NOTES

Learn, compare and create reviewable artifacts

ChatGPT is an application with model and tool capabilities, not merely the name of one LLM.

Use a conversation for explanation, iterative questions and drafts. Use a project when related work needs shared source material and instructions. When available, a task-oriented Work surface can gather sources and create larger deliverables. File processing, search, connected apps and local execution depend on the account and selected surface; inspect what is actually enabled.

ChatGPT can discuss code and Codex can explain concepts, so this is a workflow choice rather than a rigid capability split. Pick the surface that exposes the evidence needed for completion: source documents for research, or repository state and executable checks for a code change.

02 / FIELD NOTES

Use an explanation–attempt–feedback loop

The learner’s own attempt makes misunderstanding observable.

Teach me causal attention using a three-token example.
First define Q, K and V with a small diagram.
Then give me one masking question and wait for my answer.
After my attempt, explain the error and give a different case.
End with what I should verify in the original paper.

Keep a study note with your attempted answer, correction and source passage. Ask for counterexamples and assumptions. For mathematics, work through a small calculation independently. For a tool workflow, reproduce it in a disposable local project. This is a study method; it does not depend on a specific named study-mode feature.

03 / FIELD NOTES

Keep facts, interpretations and decisions distinct

A polished research answer still needs evidence inspection.

Name the sources, time range and question. Ask for a table where every factual row has a source passage or direct link. Mark the model’s synthesis separately from reported facts. Open the underlying source for important claims and test whether it actually supports the sentence. A citation can exist and still be irrelevant.

For a decision memo, specify the acceptance criteria before the comparison: correctness, integration cost, data boundaries and operational burden. For sensitive inputs, use the organization’s allowed data route and verify current product controls; do not infer retention or training use from the presence of a chat interface.
