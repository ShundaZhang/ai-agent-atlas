01 / LEARNING ROUTE

Move from concepts to observable results

Assumed background: programming and basic systems knowledge. Linear algebra and probability help with the model chapters; no paid API is required for the local exercises.

01

See the whole stack

Concepts → LLM mechanics → Training → Inference. Explain which component changes when you add data, context or tools.

02

Use evidence well

Prompting → Context / RAG → ChatGPT. Produce a source-supported comparison, including a case where the evidence is missing.

03

Operate an agent

Agents → Harness → Tools / MCP → Codex. Reproduce a small code failure, patch it and inspect the verified result.

04

Measure and improve

Evaluation → Security → Practice / Labs. Read a trace, test a denied action and compare accepted results against cost.

03 / START HERE

Four outputs worth keeping

A learning site is most useful when it turns into your own experiments.

CHATGPT

A cited study note

Explain one concept, attempt a question, and verify the correction against a source.

CODEX

A reviewed code change

State the failing property, inspect the diff, and keep the observed regression result.

HARNESS

A trace you can explain

Download the scripted local runtime and identify what was proposed, authorized, executed and verified.

EVAL

A repeatable acceptance set

Keep cases, denied actions and failure examples beside cost and latency measurements.
