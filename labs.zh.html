01 / CONTEXT

放得下的上下文仍可能缺乏证据

任务：比较当前协议需求。为指令和输出各预留 1,000 单位。

就绪 — 选择输入

示例资料：当前原文 3,000 单位，过时草案 4,000，日志 5,000，摘要 1,000。摘要遗漏精确条款。选择方案共需 5,000，全部资料共需 14,000。这是虚构计量单位，不是 token、真实注意力或费用估计。

对应资料：Lost in the Middle：长上下文研究 ↗

02 / HARNESS

建议、执行与完成是不同事件

任务：求和租户 A 公开训练账单 [40, 60]。只允许读取 A；完成要求已验证的计算结果为 100。

就绪 — 选择输入

模拟规划器输出固定序列，工具只读取内存示例。检查事件顺序及是否发生验证；未执行或错误最终答案不能标记完成。超时是模拟的，循环预算按规划步数计数。

对应资料：OpenAI：运行 SDK Agent ↗ · OpenAI：函数调用 ↗

03 / EVALUATION

比较每项可接受任务成本

三个虚构候选各运行相同六个任务一次。C 有一项阻塞，仍保留在分母中。

就绪 — 选择输入

任务分数 ≥ 0.8 满足质量阈值；严格验收还要求无未获准效果。成本为任意单位，阻塞尝试仍计入列出的成本。小型固定数据只演示指标定义，不代表产品性能比较。

对应资料：OpenAI：评估方法 ↗

04 / LOCAL CODE

阅读并运行最小教学 Harness

Python 标准库示例，使用脚本化规划器，不是 LLM 或 SDK。

下载 toy_harness.py ↓ · 下载检查文件 ↓

python3 toy_harness.py success --max-steps 4
python3 toy_harness.py denied
python3 -m unittest -v test_toy_harness.py

将两个文件放在同一可丢弃目录。程序读取内存示例并打印 JSON 事件，不使用网络、写文件、子进程或凭据。验证为此任务刻意限定，不是生产沙箱或安全库。
