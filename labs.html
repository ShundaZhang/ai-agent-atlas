01 / CONTEXT

A fitting context can still lack evidence

Task: compare the current protocol requirements. Reserve 1,000 units for instructions and 1,000 for the output.

Ready — choose an input

Synthetic material: current source excerpt 3,000 units, stale draft 4,000, logs 5,000, summary 1,000. The summary omits the exact clause. Selection needs 5,000 units; all documents need 14,000. These are invented accounting units, not tokens, actual attention or billing estimates.

02 / HARNESS

Proposal, execution and completion are distinct events

Task: sum tenant A’s public training invoices [40, 60]. The only allowed read is tenant A; final completion requires a validated computation result of 100.

Ready — choose an input

The fake planner emits a fixed sequence. Tools read only in-memory fixtures. Inspect the event order and whether verification occurs; an unexecuted or wrong final answer must not be marked complete. A timeout is simulated and the loop budget counts planner steps.

03 / EVALUATION

Compare cost per accepted task

Three invented candidates run the same six tasks, each once. Candidate C is blocked on one task; that case stays in the denominator.

Ready — choose an input

A task passes the quality threshold at score ≥ 0.8. Strict acceptance also requires no unauthorized effect. Costs use arbitrary units, and blocked attempts still incur their listed cost. This tiny fixed dataset demonstrates metric definitions, not comparative product performance.

04 / LOCAL CODE

Read and run a minimal teaching Harness

A Python standard-library example with a scripted planner, not an LLM or an SDK.

Download toy_harness.py ↓ · Download its checks ↓

python3 toy_harness.py success --max-steps 4
python3 toy_harness.py denied
python3 -m unittest -v test_toy_harness.py

Save both files into the same disposable directory. The program reads synthetic fixtures from memory and prints JSON events. It has no network, file writes, subprocesses or credentials. Its validation is deliberately narrow for this task; it is not a production sandbox or a security library.
